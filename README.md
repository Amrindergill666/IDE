# IDE-client

This is the client-side application for the Vite IDE project. It is built using modern web technologies to provide a seamless and efficient development experience.

## Features

- **Fast and Lightweight**: Powered by Vite for blazing-fast development.
- **Modular Architecture**: Easy to extend and maintain.
- **Cross-Platform**: Works on all major browsers.
- **Developer-Friendly**: Intuitive UI and robust tooling.

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/IDE-client.git
    ```
2. Navigate to the project directory:
    ```bash
    cd IDE-client
    ```
3. Install dependencies:
    ```bash
    npm install
    ```

## Usage

To start the development server:
```bash
npm run dev
```

To build the project for production:
```bash
npm run build
```

To preview the production build:
```bash
npm run preview
```
